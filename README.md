# ZipLoc - CRM de Locação de Equipamentos

Sistema de gestão para locadoras de equipamentos desenvolvido numa arquitetura de Monólito Modular. O projeto visa centralizar e automatizar o controlo de clientes, a gestão do catálogo e das unidades físicas de equipamentos, o ciclo de vida dos contratos de locação, vistorias, manutenções e o faturamento.

## Stack Tecnológica

### Back-end
* Java 21 LTS
* Spring Boot 3.x
* Spring Security (Autenticação JWT Stateless)
* Spring Data JPA (Hibernate)
* Flyway Migration (Versionamento da base de dados)

### Front-end
* TypeScript
* React 18
* Vite
* React Router DOM
* React Hook Form + Zod (Validação de dados)

### Infraestrutura e Base de Dados
* PostgreSQL 16
* Docker
